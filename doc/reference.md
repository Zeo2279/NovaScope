## 拜尔阵列简介

​	这里我们也简单介绍一下拜耳阵列。

​	拜耳阵列解决了图像传感器只能感受光强而不能感受波长，导致无法记录颜色的问题。在图像传感器前面设置一层彩色滤光片阵列 ，有间隔的在每个像素上放置单一颜色的滤镜，如下图所示，光线经过拜耳滤光片，获取到R、G、B三个通道的图像，由于人眼对绿色更为敏感，G通道有1/2的像素被填充，而R通道和B通道分别只有1/4的像素被填充。再通过算法，将像素点R、G、B三个通道的原始图进行填充，就可以得到完备的彩色图像。

## bayer2rgb

​	bayer转RGB的算法有很多种，这里介绍一种简单的**双线性插值法**，即通过相邻像素的平均值来估算缺失的颜色值。

![bayer pix](./img/20190927164854302.png)

​	具体来说，图中**非**绿色像素点计算绿色通道值的原理是将上，下，左和右像素值的**平均值**指定为插值像素的G值。 例如：G8 =（G3 + G7 + G9 + G13）/ 4。

​	相应的，**红色/蓝色**像素在**绿色**位置的插值：将对应颜色的两个相邻像素值的平均值分配给插值像素。 例如：B7 =（B6 + B8）/ 2; R7 =（R2 + R12）/ 2

​	**红色/蓝色**像素在**蓝色/红色**位置的插值：将四个相邻对角像素值的平均值分配给该插值像素。 例如：R8 =（R2 + R4 + R12 + R14）/ 4; B12 =（B6 + B8 + B16 + B18）/ 4

​	虽然原理和实现都很简单，但因为仅使用邻近像素的平均值，容易导致边缘模糊或色彩伪影。

​	在FPGA的实现中，我们需要缓存两行图像数据，加上当前输入的一行，才能实现以上的算法，同时需要一个计数器来判断当前计算行的像素对应的是绿红绿红还是蓝绿蓝绿。平均值的计算也很简单，除以2和除以4分别将**相邻像素和**右移一位和两位即可实现。缓存两行的具体实现我们放到后面介绍**降噪一章**时详细介绍。

**实现内窥ISP图像处理（AE AWB 消光 降噪 延时等功能）**

---

​	ISP是Image Signal Processing的缩写，即图像信号处理。之前我们展示了内窥镜不同的应用场景，不同应用场景下图像处理的侧重点也有不同，简单来说，医疗场景下更多的追求图像的还原度，让医生看到接近肉眼观察的组织颜色，工业场景下更需要将缺陷特征放大，便于观察。本次赛题没有指定应用场景，同学们可以根据自己情况选择一种或几种便于展示验证的应用环境，实现对应的图像处理算法。我们先围绕指标3指定的功能进行讲解，后面按医疗应用场景来扩充指标3的算法。

## 1.AE

### 1.1 AE简介

​	 AE是Automatic Exposure的简称，即自动曝光。

​	曝光量的本质是感光介质接收的光量，与光圈、时长以及iso有关，三者组合决定了传感器最终输出图像的亮度。
​	自动曝光是指在图像处理中通过动态调节参数，确保在不同光照条件下捕获亮度均衡、细节清晰的图像，避免过曝或欠曝。

​	下图展示了肉眼所见的亮度和直方图两种维度进行不同曝光的对比。

![5b46d4cb0e966a0bae7f2fa7feebfbc5](./img/5b46d4cb0e966a0bae7f2fa7feebfbc5.png)

### 1.2 算法原理

​	自动曝光的算法有很多种，为了便于FPGA实现，可以选用2种原理相对简单的方法：灰度均值法和加权灰度均值法。

​	灰度均值法通过计算整幅图像的灰度（亮度）均值Y来评估整体亮度，而加权灰度均值法则将图像等分为N个区域，分别计算每个区域的灰度均值Yi，并为每个区域赋予不同的权重系数Fi，最终加权得到整幅图像的灰度均值Y。

​	为了实现自动曝光控制，需设定一个目标灰度均值Yt，并将当前图像的灰度均值Y与Yt进行比较，得到差值∆Y = Yt - Y。该差值用于计算下一帧的曝光时间调整值，从而优化图像亮度。

​	自动曝光的核心要求包括快速响应和快速收敛。快速响应确保曝光时间调整能够及时跟随光照变化，使得图像亮度迅速达到稳定状态，减少延迟时间。快速收敛则保证当图像亮度接近目标值并在小范围内波动时，曝光时间能够迅速稳定，避免过度调节。为了满足这两个条件，设定一个最小灰度均值差∆Ymin，当|∆Y| ≤ ∆Ymin时，认为自动曝光已收敛，无需进一步调整曝光时间。

​	默认情况下，CMOS传感器输出的图像亮度与光照强度近似呈线性关系。当|∆Y| > ∆Ymin时，表明当前图像亮度与目标值仍有明显偏差，需调整曝光时间。已知当前帧的曝光时间为T，根据曝光时间调节步长∆T的计算公式计算出 ∆T。最终，下一帧的曝光时间Tn = T + ∆T，通过动态调整曝光时间，使图像亮度逐步逼近目标值，实现稳定且高效的自动曝光控制。

### 1.3 FPGA实现流程

​	自动曝光的实现流程

![AE框图](./img/AE%E6%A1%86%E5%9B%BE.png)

​	因为 AE 只关心 **亮度信息**，可以用 **Bayer RAW 数据的加权和**（尤其是绿通道，因为绿点密度最高，最接近人眼亮度感知）来估算亮度

​	如果在bayer2rgb之后来做AE，那么在计算均值前需要将图像灰度化。灰度化的实现很简单，将rgb做一次公式计算即可得到亮度值Y，公式：`Y = 0.299R + 0.587G + 0.114B`，当然计算上需要考虑硬件的实现，将小数化为整数，乘除法用移位来替代。具体来说，可以通过将公式整体扩大 256 倍，例如 0.299*256≈77。这样做会损失部分精度，要求高精度的话可以扩大更大的倍数，倍数越大，结果越准确。所以 0.299R 就转为 77R，最后再把计算结果>>8 位即可，相当于除以 256，我们通过移位操作可以大大降低运算难度。

​	（1）图像采集和图像配置可使用MIPI CSI 核实现

​	（2）分块处理模块中，将输入图像**按关注程度**划分为N个区域，计算各区域灰度均Yi，再根据**权重系数** 加权求和，得到全局灰度均值 Y（优化除法为乘法运算）

​	（3）Y值比较模块中比较 Y与目标值 Yt，生成差值 ΔY。若 `|ΔY| ≤ ΔYmin`，判定为收敛状态，停止调节；否则通过**查找表（LUT）** 快速获取调整曝光时间的步长 `ΔT`。

​	（4）曝光时间调整，根据公式 `Tn = T + ΔT` 计算新曝光时间，输出调整后的曝光时间Tn至摄像头配置模块。

## 2. AWB

### 2.1 AWB简介

​	AWB（Auto White Balance）即为自动白平衡，自动白平衡就是通过算法将不同色温的环境光下成像后的白色还原成真实的白色（通常为自然日光环境光下的人观察到的白色）。

​	使用AWB的原因是传感器无法跟人一样根据环境光的变化而改变感光特性，所以需要额外的模块来模拟人的感知特性，将不同环境光下的白色还原成真实的白色。

### 2.2 算法原理

​	自动白平衡的算法也有很多种，为了便于FPGA实现，可以选用原理相对简单的方法：**灰度世界法**。

​	其核心原理基于自然场景中所有颜色的平均反射光应趋近于中性灰的**假设**，即R、G、B三个通道的**均值应大致相等**。
​	实现时先计算图像各通道均值，以通道**最大值的一半为基准**，若数据位宽为8bit则一半为128，接着，分别计算各通道的**增益系数**，即用该基准值除以对应通道的均值，确定R、G、B三个通道的调整比例。然后将每个像素的R、G、B值**乘以对应增益系数**，以实现颜色校正。这种方法通过简单的均值计算和增益调整即可实现白平衡，适合FPGA高效处理，同时能有效消除图像色偏。

### 2.3 FPGA实现流程

​	自动白平衡的实现流程示意图

![AWB框图-1754558691235-11](./img/AWB%E6%A1%86%E5%9B%BE-1754558691235-11.png)

1. 先是在三通道累加器模块统计每帧图像的**各通道总值**

2. 在通道均值计算模块中，将各通道总值除以图像分辨率**计算各通道均值**，这里可以通过定点数乘法替代除法，截取整数部分作为均值输出。
3. 在倒数查找表模块中，我们提前通过MATLAB生成**1~255的倒数并与基准值相乘**得到增益系数，预存到FPGA的ROM中，输入均值即可**查找**对应增益系数。
4. 最后在像素校正模块中将增益系数应用到各通道，即，将每个像素的R、G、B分量分别**乘以**对应的**增益系数**，若计算后的像素值超出有效范围（如8位数据超过255），则固定至最大值（如255），最后得到经过白平衡校正的图像。

## 3. 消光

### 3.1 消光简介

​	图像做消光处理主要是为了在医疗应用场景下减少光源照射到器官表面液体或湿润组织带来的反光，避免出现一片白花的情况，丢失细节。

### 3.2 算法原理

​	消光首先是要检测高光，因为高光区域通常亮度高、饱和度低，可以利用亮度阈值快速检测过曝像素再结合颜色饱和度判断。再对高光区域进行亮度压缩，降低区域亮度。最后通过周边像素插值来对细节进行补偿，恢复纹理信息。

### 3.3 FPGA实现流程

![image-20250816152103830](./img/image-20250816152103830.png)

​	在上面AE中已介绍了亮度转换，这里还需要判断饱和度，因此还需要实现RGB2HSV的转换，HSV颜色空间也是一种常用的颜色表示方式，更贴近人类对颜色的感知。它由三个分量组成：色相、饱和度和亮度。HSV的亮度是直接取 RGB 三个通道的最大值，而YUV的亮度更符合人眼亮度的感知，因此保留了Y值的计算。

![img](./img/250px-Triangulo_HSV.png)

​	之后通过比较阈值，判断是否需要调节亮度。

​	亮度压缩可以采用亮度映射的方式，通常有Gamma/Log/S型曲线等映射方式，本质都是通过**查表**的方式找到输入亮度所对应的校正后的值，只是不同映射的效果不同。这一步对前面判断的超出阈值的像素进行查表处理。

​	之后再结合反光区域周围的像素，进行插值运算来恢复出反光区域的纹理。

​	在某些手术场景下，医生会主动利用反光来判断表面湿度，因此ISP需要支持**可调节消光强度**。

## 4. 降噪

### 4.1 降噪简介

​	图像降噪处理主要分为**2D**与**3D**降噪

​	ISP中通常包括对图像的去噪，英文名称为Image Denoising。是指的对数字图像中的噪声进行消除或减少的过程。2D去噪指的是对**单帧图像**进行帧内降噪处理，而3D去噪则需要关联前后帧。

​	因此可以先实现简单的2D降噪，再后续优化的时候可以改为3D降噪。常见的2D降噪有均值滤波、中值滤波、高斯滤波等。

| 滤波类型 | 原理                           | 优点                       | 缺点                       |
| -------- | ------------------------------ | -------------------------- | -------------------------- |
| 均值滤波 | 用邻域像素的平均值替换中心像素 | 计算简单，实时性高         | 模糊边缘，对椒盐噪声效果差 |
| 中值滤波 | 用邻域像素的中值替换中心像素   | 有效抑制椒盐噪声，保留边缘 | 计算量较大（需排序）       |
| 高斯滤波 | 用高斯加权平均值替换中心像素   | 平滑效果好，保留边缘过渡   | 对椒盐噪声不敏感           |

### 4.2算法原理

​	这里介绍一个简单的均值滤波算法。

​	均值滤波是一种典型的线性滤波算法。原理很简单，以当前处理像素为中心，取n x n大小的图像矩阵，求出该矩阵内的像素的均值替代该像素，如此遍历整个图像，即可完成整幅图像的均值滤波。均值滤波计算简单，实时性高，但整体模糊边缘，对椒盐噪声效果差。

## 5. 延时

​	延迟不是像之前那些指标一样通过某个具体方法来实现，低延迟是一个系统级特性，它需要各个模块都按照最小延迟的原则进行设计。

​	一个基本的原则是，所有针对图像的处理必须是以**行**为单位，而不是以帧为单位。

​	如果以帧为单位，需要输出完整一帧再开始进行处理，就会有一帧图像输出的延迟，以行为单位进行处理，则只需要等待一行的输出延迟

## 1.优化之前实现的算法

**bayer2rgb去马赛克算法：**

​	之前的双线性插值算法实现简单，不过效果不算很好，其他的一些算法在插值过程中还会考虑邻域色彩的梯度，根据梯度对插值结果进行补偿或校正。考虑到在FPGA中实现的效果和资源使用问题，可以选取一种经典的算法：梯度校正线性插值 gradient-corrected linear interpolation。

**AE中可以使用直方图法进行优化**

​	均值法是不适用于场景中**背景色彩单一**的情况：比如背景中白色较多，出现视觉误差，出现欠曝，反之当背景全黑时，或者黑色较多的时候，就会出现过曝
​	在均值法的基础上，引入了直方图统计的方法。同学后续优化可改用**直方图统计**来对曝光进行调整。

**AWB中可以使用动态阈值算法进行优化**

​	灰度世界法选取的是固定的基准值，而动态阈值算法是根据图像的统计特性来计算阈值。

**消光可使用AE快速收敛+HDR算法**

​	其实是一种在**ISP链路前端**就降低反光高光影响的策略，跟上述的“检测高光 → 局部亮度压缩”有区别，它更像是**曝光控制 + 多曝光合成**的联合方案。

## 3.提高清晰度

​	增加清晰度，在靠近边缘较暗的一侧会变得更暗，靠近边缘较亮的一侧会变得更亮，但这种亮度对比的变化只局限在边缘周围的部分。

​	清晰度相当于让边缘亮的一边加上一根白色渐变条，暗的一边加上一根黑色渐变条，从而让物体轮廓和细节纹理更加清晰。

## 4.图像增强

​	图像增强与锐化技术在内窥镜图像预处理与优化中的应用是至关重要的，因为内窥镜图像往往受到多种因素的影响，如光照不均、对比度低、噪声干扰等，这些因素都会影响图像的视觉效果和后续的图像分析结果。

​	**直方图均衡化**是一种常用的图像增强方法，它通过调整图像的直方图分布，使图像的对比度得到改善。这种方法特别适用于图像的局部对比度较低，整体亮度不均匀的情况。直方图均衡化可以增加图像的**局部对比度**，提高图像的可视性。
